01. 대시보드 설명

엣지·보링 설비
날물 교체관리 대시보드

엣지 설비의 AT날물과 보링 설비의 직경별 보링날 교체 상태를 관리하고
교체 이력을 데이터로 축적하기 위한 시스템

엣지 설비

1. AT날물 관리
2. 엣지 공정에서 앞·뒤 끝단을 절삭, 정리하여 엣지 접착 전 마감 상태를 안정화하는 날물
3. 날물 마모나 파손 시 끝단 깨짐, 쪽떨어짐 등 외관 품질 문제가 발생할 수 있어 관리가 필요

보링 설비

1. 5Ø(관통), 8Ø(관통), 12Ø(관통), 15Ø, 20Ø, 35Ø 날물 관리
2. 직경별 날물 상태는 보링 깊이, 치수 불량에 영향을 미칠 수 있기에 관리가 필요

02. 대시보드 화면

대시보드 주요 화면

설비별 날물 사용률, 교체상태, 데이터 반영 이력, 교체완료 시점을 한 화면에서 확인 가능

대시보드 바로가기 ↗

설비별 날물 사용률과 교체상태를 한눈에 확인

데이터 반영 이력과 교체완료 시점 기록 관리

03. 도입 배경

왜 만들었는가?

교체 누락 방지

수기 관리와 작업자 경험 의존을 줄이고 교체 시점을 한눈에 확인

품질 불량 예방

엣지 쪽떨어짐, 보링 깊이 불량, 보링 치수 불량 등을 사전에 예방

04. 데이터 추출

보링 매크로와 ERP 데이터를 통합

보링 매크로 파일에서 날물 정보를 추출하고, ERP 생산 데이터를 함께 연결해 대시보드에 반영

1

보링 매크로 추출

보링 설비의 매크로 파일을 추출해 날물별 사용 정보를 확인

2

ERP 데이터 추출

ERP에서 설비별 생산량과 사용 실적 데이터를 가져옴

3

통합 데이터 생성

매크로 파일과 ERP 데이터를 엮어 날물별 사용량을 정리

4

대시보드 반영

통합 데이터를 기준으로 사용률과 교체상태를 표시

보링 매크로 파일 추출 과정 영상

ERP에서 생산·사용 실적 데이터를 추출

ERP 데이터와 보링 매크로 데이터를 연결한 통합 데이터

05. 사용 방법

날물 이상이 없는 경우

교체상태가 교체필요이지만 날물 확인 결과 이상이 없을 경우, 비고란에 내용을 남겨 데이터를 축적

1. 교체필요 상태 확인

사용량 100% 도달 설비를 확인하고 담당자를 입력한 뒤 교체 처리

→

2. 비고 내용 입력

교체완료 시점 입력 영역에서 비고란에 날물 이상 없음 등의 내용을 기록

→

3. 사용량 초기화

처리 완료 후 사용량이 0%로 초기화되고 상태는 정상으로 다시 관리

05. 사용 방법

날물 이상이 있는 경우

교체상태가 교체필요이고, 현장에서 확인했을 때 실제로 날물 이상이 있는 경우의 처리 방식

1

날물 확인

교체필요 상태의 설비를 확인하고 실제 이상 여부를 판단

2

담당자 입력

교체를 진행하는 담당자를 입력

3

교체필요 클릭

교체필요 버튼을 눌러 즉시 교체 완료 처리

4

이력 저장

사용량은 0%로 초기화되고 교체완료 이력에 기록

06. 사용 방법

교체상태가 ‘정상’인 경우

사용량이 100%가 아니어도 현장에서 날물 이상이 발생하면 즉시 교체할 수 있음

1. 담당자 입력 후 정상 버튼 클릭

정상 상태의 설비라도 현장에서 이상이 확인되면 담당자를 입력하고 정상 버튼을 눌러 교체 절차를 시작

→

2. 교체 이유 입력

팝업 창에서 담당자와 교체 이유를 입력한 뒤 교체 처리 버튼을 눌러 완료

→

3. 교체완료 및 사용량 초기화

처리 완료 후 사용량이 0%로 초기화되고 교체완료 상태로 반영

→

4. 교체 이력 저장

교체완료 시점 영역에 담당자와 비고 내용이 저장되어 이후 이력 관리와 분석에 활용

07. 마무리

기대 효과

품질 문제 사전 대응

날물 이상으로 인한 엣지 마감 불량, 보링 깊이·치수 불량을 사전에 파악하고 대응

관리 효율 향상

설비별 교체 현황과 교체 이력을 한 화면에서 확인하여 관리 시간을 줄임
